## Repository Context

This repository is **not the official ECC project** and should not be treated as an original DoubleCore implementation.

ECC and its agent configurations, skills, hooks, rules, memory systems, security tooling, and related packages are created and maintained by the upstream project and contributors.

I keep this fork to study a broader question:

> What does a complete engineering system around coding agents look like once prompts are no longer enough?

## What I Am Studying

- reusable agent skills and specialized agents;
- hooks and policy enforcement;
- persistent context and memory;
- planning, testing, review, and verification loops;
- agent security and permission boundaries;
- cross-tool configuration patterns;
- how engineering practices can be encoded into an agent harness.

## Relation to My Training

This repository belongs to the **AI engineering methods** side of my Professional AI Player portfolio. The important lesson is not the number of prompts or agents; it is how a system can make AI-assisted development more repeatable and auditable.

```text
plan -> test -> implement -> review -> verify -> learn
```
